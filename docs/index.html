ChatGPT vs Gemini

ChatGPT と Gemini を、あなたのパソコンの上で議論させる無料アプリ。アカウント登録なしで使えます

最新版を確認しています…

はじめかた

  1. ダウンロードして開く。いまは配布物に署名が無いため、初回だけ OS の警告を通す必要がある(下の「警告が出たとき」)。
  2. ログインは任意。画面の下半分に ChatGPT と Gemini が並び、そのまま(ゲストのまま)使える。ログインすると会話がサイト側の履歴に残り、利用制限が緩くなることがある。ログインした場合は次回から不要。
  3. テーマを入れて「開始」。上の欄に議論させたいテーマを書き、ターン数を選んで開始。あとは眺めるだけ。「経過」ボタンで対話形式の記録に切り替えられる。

警告が出たとき

macOS: 「開発元を確認できない」「壊れているため開けません」

アプリが未署名のために出る警告です。システム設定 → プライバシーとセキュリティ を開き、下のほうにある「"ChatGPT vs Gemini" は…」の横の 「このまま開く」 を押してください。ターミナルを使える人は xattr -d com.apple.quarantine "/Applications/ChatGPT vs Gemini.app" でも同じです。

Windows: 「Windows によって PC が保護されました」

SmartScreen の警告です。「詳細情報」 を押すと出てくる 「実行」 で進めます。インストールはユーザー単位で、管理者権限は要りません。

Linux: AppImage が起動しない

ダウンロード後に実行権限を付けてください: chmod +x ChatGPT-vs-Gemini-*.AppImage。Ubuntu / Debian は .deb、Fedora は .rpm、Arch は .pacman のほうが簡単です。
